# Graph Lab (core plugin)

Interactive graphing for every math topic: functions, implicit curves, inequalities,
parametric and polar curves, sliders, calculus, complex numbers (domain coloring), matrix
transformations and 3D surfaces. Use it from the sidebar, or let the tutor show live graphs
in lessons with ```` ```graph ```` blocks. Exam Prep embeds its calculator for exams that
allow one. Design: `docs/exam-prep-design.md` in the app repository.
