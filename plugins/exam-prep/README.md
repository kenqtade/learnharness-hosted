# Exam Prep (core plugin)

**Question Bank** — carefully written, skill-linked questions: authored by AI and checked by
an independent solver and critic, sourced from the web with the source kept, or imported
from past papers. **Exam Simulator** — realistic timed simulations of official exams (SAT,
ACT, IELTS, A-Level, IB, Ethiopian national exam, or any exam the AI researches), with
exactly the tools each section allows.

Design: `docs/exam-prep-design.md` in the app repository. AI features use your configured
models and can incur cost; nothing runs until you start it.
